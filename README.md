# Winner Apparels – Garments Management

- `frontend/` – the web app (static build, deploy on Vercel with root directory `frontend`).
- `backend/` – Express API skeleton (`npm install && npm start`).

Note: the app was exported from a compiled bundle, so `frontend/assets/app.js` is minified and has no readable source. The app currently keeps its data in the browser; the backend is a starting point.
